## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Главная собирается заново из четырёх блоков Moni (слайд 10), которые владелец отобрал при разборе: header с аватаром и приветствием, крупный общий баланс, полоса карточек счетов, две плитки статистики с дельтой, донат бюджета. Блок Goals референса не переносим — целей-копилок у нас нет.

Две замены против референса. Колокольчик уведомлений не берём: уведомлений нет, и его место справа в header занимает переключатель базовой валюты. И главное, чего у Moni нет вовсе: общий баланс сведён из двенадцати валют, поэтому под ним обязана стоять сноска, по какому курсу и на какую дату он посчитан — без неё цифра врёт.

Чистое ядро dashboard (buildDashboard) — расчёт, его трогать не нужно; задача переделывает представление.
<!-- SECTION:DESCRIPTION:END -->

7. Тесты: обновить DashboardPage.test.ts и build-dashboard.test.ts; /impeccable по экрану; bun run test, lint, typecheck.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Решения владельца: строка «доступно до зарплаты» переехала под общий баланс, «Ближайшие 30 дней» остался внизу на строках операций (TASK-010); таблица «План месяца» и список поступлений по источникам убраны — они целиком есть на экране План. Вторая плитка — «План трат» (фактических трат в базе нет до фазы 5), донат — плановые траты из чистого дохода с остатком в разрыве кольца.

Данные: buildDashboard получил stats.income (фактические Inflow месяца) и stats.outgo (плановые траты) с дельтой к прошлому месяцу; прошлый месяц считается теми же чистыми функциями на дату addDays(firstOfMonth(today), -1). useDashboard тянет Inflow за два месяца одним запросом.

По дороге найдены и исправлены три настоящие ошибки:
1. packages/ui DonutChart в режиме progress всегда рисовал полное кольцо — layoutDonut нормализовал единственный сегмент сам на себя. Добавлен параметр whole; регрессионные тесты в donut.test.ts.
2. packages/ui AccountCardStrip передавал плитке добавления href=undefined поверх router-link, из-за чего у <a> не было href и он не получал фокус с клавиатуры. Тест в account-card.test.ts.
3. Переключатель валюты исчезал на Главной: синглтон useDisplayCurrency привязывался к профильному запросу, созданному в скоупе асинхронной страницы. Теперь его владелец — App.vue (композиционный корень).

Проверка вживую: локальный стек (supabase + api + vite), сессия владельца, 4 снимка Playwright (320 и 1280 px × светлая и тёмная). Замеры DOM: горизонтального переполнения нет, ярлык плитки не обрезается (68 px при 78 доступных), переключатель валюты присутствует на обеих ширинах.

Оговорка по офлайну: окно запроса Inflow изменилось (два месяца вместо одного), поэтому при первом холодном запуске после обновления персистентный кеш не содержит старого ключа — поступления месяца подтянутся при первом соединении. Мутации и их оптимистичные вставки не затронуты (matchesInflowParams), income-offline и offline-mutations проходят.
