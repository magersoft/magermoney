## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
У Moni доходы и расходы показаны парой плиток: иконка в цветном кружке, бейдж изменения к прошлому месяцу (+5% со стрелкой), метка и сумма, шеврон перехода (слайды 10, 12, 14). Это то место, где приложение отвечает на вторую половину вопроса владельца — больше ли, чем в прошлом месяце.

Плитка нужна главной и экрану счёта. Правило цвета из direction.md здесь работает буквально: сумма чернильная, цвет получает только бейдж дельты, и зелёный в бейдже — заливка, а не текст.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Плитка показывает иконку, метку, сумму через amount lockup и бейдж дельты
- [ ] #2 Сумма чернильная; цветом окрашен только бейдж дельты
- [ ] #3 Направление дельты передано не одним цветом: есть стрелка или знак
- [ ] #4 Нулевая и отсутствующая дельта обработаны и не показывают пустой бейдж
- [ ] #5 Плитка может быть ссылкой: цель нажатия >=44px, фокус виден
- [ ] #6 Проходит AA в обеих темах, включая бейдж на заливке
- [ ] #7 Тесты покрывают рост, падение, нулевую и отсутствующую дельту
- [ ] #8 bun run test, lint, typecheck проходят
