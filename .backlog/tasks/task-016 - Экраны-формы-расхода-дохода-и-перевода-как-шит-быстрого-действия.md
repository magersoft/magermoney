## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Сейчас до добавления расхода три касания через План, и формы живут отдельными маршрутами с обычными полями. Референс решает это прямо (слайд 13): центральная кнопка + раскрывает шит, где сумма — первое и самое крупное поле, под ней сегмент типа операции, дальше поля-строки, внизу кнопка.

Задача переводит три наши формы на этот паттерн: перевод, расход, доход (долгов и скана чека у нас нет). Рядом с суммой стоит селектор валюты, которого у одновалютного Moni нет. Маршруты форм остаются — на них ведут ссылки из Плана и с экрана счёта, — но их содержимое становится тем же шитом, и та же форма открывается из + в навигации.

Правки валидации и того, что формы отправляют, в эту задачу не входят: меняется только представление.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Реализовано.

packages/ui: добавлены InputRow и SelectRow (поля-строки 56px с подписью-label и объявленной ошибкой) + field-rows.test.ts. QuickActionSheet: $attrs теперь садятся на панель (корень — renderless DialogRoot), у кнопки подтверждения data-slot и цель 48px, добавлен слот secondary.

Три формы собраны из шита: ExpenseSheet, IncomeSourceSheet, TransferSheet. Маршруты /plan/expenses/*, /plan/income/* стали тонкими обёртками над теми же шитами, так что ссылки продолжают работать. Отправляемые данные не менялись — изменилось только место ввода.

OperationSheet (модуль plan, композиция соседей через барели) держит сегмент «Перевод / Расход / Доход» и монтирует ровно один шит за раз. Источник дохода грузится лениво (routeComponent), иначе весь income-модуль попадал бы в entry-чанк.

«+» в навигации теперь открывает сам шит, а не меню из трёх кнопок: до записи расхода одно касание вместо трёх. Поступление и «обновить остаток» — не операции плана, поэтому остались рядом, в слоте secondary того же шита.

Валидация: кнопка больше не заблокирована молча — нажатие показывает ошибку на том поле, где её ждут, с aria-invalid и aria-describedby; при ошибке отправки шит остаётся открытым, введённое не теряется.

Проверка: bun run test (web 236, ui 240), lint, typecheck зелёные. В браузере на 420px в обеих темах: шит, строки 56px, кнопка 48px, без горизонтального скролла. Данных без сессии к API нет, поэтому списки валют/счетов в браузере пустые.
