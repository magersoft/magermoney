## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Два самых частых ряда во всём приложении. Строка операции у Moni: иконка слева, название и категория в две строки, сумма справа, время под суммой (слайды 12, 14). Строка категории бюджета: иконка-эмодзи, название, пара потрачено/лимит и собственная полоса прогресса, красная при превышении (слайд 16).

С переходом на язык Moni ряды перестают разделяться хайрлайнами — их группирует карточка, внутри которой они лежат. Списки ещё и группируются с подытогом в заголовке группы. Обе строки нужны экранам Счёт, План и Бюджеты, плюс их наследуют курсы, переводы и настройки, поэтому это общий компонент, а не разметка внутри экрана.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Строка операции показывает иконку, название, категорию, сумму через amount lockup и время
- [ ] #2 Строка категории показывает эмодзи, название, пару потрачено/лимит и полосу прогресса
- [ ] #3 Превышение лимита передано не только цветом полосы
- [ ] #4 Строка категории несёт валюту бюджета, если она отличается от базовой
- [ ] #5 Есть заголовок группы с подытогом справа
- [ ] #6 Строка может быть ссылкой: цель нажатия >=44px, фокус виден, шеврон не перехватывает нажатие
- [ ] #7 Ряды группируются карточкой, а не разделительными линиями; длинное название усекается без слома суммы
- [ ] #8 Тесты покрывают обе строки, превышение лимита, группу с подытогом, длинное название
- [ ] #9 bun run test, lint, typecheck проходят
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Тесты сначала: `packages/ui/test/row.test.ts` — обе строки, превышение лимита, группа с подытогом, длинное название, ссылка и шеврон.
2. `components/row/TransactionRow.vue`: иконка в плашке (слот), название и категория в две строки, сумма через AmountLockup справа, время под суммой. `Primitive` с `as`, как у StatTile, чтобы экран отдал `router-link`.
3. `components/row/CategoryRow.vue`: эмодзи, название, пара потрачено/лимит, собственная полоса. Превышение — `data-over`, красная полоса плюс слова и иконка. Валюта бюджета показывается кодом через `showCode`, когда отличается от базовой.
4. `components/row/RowGroup.vue` + `RowGroupHeader.vue`: заголовок группы с подытогом справа, ряды лежат в карточке, без разделительных линий.
5. Сумма в строке — чернила (правило direction.md), знак несёт само число; `variant` прокинут для случаев, где строка действительно про изменение.
6. Экспорт из `packages/ui/src/index.ts`; test, lint, typecheck.
