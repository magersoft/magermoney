## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Мастер нового бюджета у Moni (слайд 16) идёт пятью шагами: имя, период, выбор категорий чипами с эмодзи, лимит на каждую категорию, подтверждение. Внизу — полоса прогресса шагов и пилюля Next со стрелкой.

Наша текущая форма бюджета показывает всё сразу, и выбор категорий с лимитами в ней самая тяжёлая часть. Задача переводит её на тот же мастер, оставляя набор полей прежним и добавляя выбор валюты бюджета, которого у Moni нет.

Premium, Personal/Family и приглашение участника из референса не переносим.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Реализовано.

По решению владельца один проход мастера создаёт несколько бюджетов: у нас Budget — это и есть категория с лимитом, а в референсе бюджет держит несколько категорий. Шаги: период → валюта → категории → лимиты → подтверждение.

budget-draft.ts — чистая логика черновика (шаги, завершённость шага, сборка BudgetInput[]) + budget-draft.test.ts. domain/palette.ts — стартовая палитра из восьми категорий с эмодзи; названия живут в локалях, своя категория вводится руками.

BudgetWizard.vue: ProgressRule внизу, пилюля «Дальше» со стрелкой, ссылка назад слева — раскладка футера из слайда 08. Черновик один объект, поэтому шаг назад ничего не теряет. Текущий шаг объявляется строкой aria-live «Шаг N из 5», у каждого шага своя группа, названная заголовком.

Редактирование одного бюджета осталось обычной формой: пять шагов ради одного числа были бы церемонией.

Выход из непустого мастера спрашивает подтверждение. Сторож висит на роутере (router.beforeEach со снятием при размонтировании), а не onBeforeRouteLeave: маршрутные экраны здесь заворачиваются в асинхронную обёртку, и внутрикомпонентный сторож в ней не срабатывает.

Проверка: bun run test (web 248, включая 9 тестов мастера и 7 тестов черновика), lint, typecheck зелёные. В браузере на 420px в обеих темах пройдены шаги 1→4: чипы заливаются акцентом (oklch 0.574 0.18 262, белый текст), прогресс 20%→80%, «Дальше» заблокирована на незавершённом шаге, без горизонтального скролла.

## Final Summary

Черновик и правила шагов вынесены в чистый budget-draft.ts. Редактирование одного бюджета осталось обычной формой. Выход из непустого мастера спрашивает подтверждение (сторож на роутере). Проверено: bun run test (web 248 тестов, из них 9 на мастер и 7 на черновик), lint, typecheck; в браузере на 420px в обеих темах пройдены шаги 1→4, чипы заливаются акцентом, «Дальше» заблокирована на незавершённом шаге.
