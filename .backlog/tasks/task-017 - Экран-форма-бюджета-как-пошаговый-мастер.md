## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Мастер нового бюджета у Moni (слайд 16) идёт пятью шагами: имя, период, выбор категорий чипами с эмодзи, лимит на каждую категорию, подтверждение. Внизу — полоса прогресса шагов и пилюля Next со стрелкой.

Наша текущая форма бюджета показывает всё сразу, и выбор категорий с лимитами в ней самая тяжёлая часть. Задача переводит её на тот же мастер, оставляя набор полей прежним и добавляя выбор валюты бюджета, которого у Moni нет.

Premium, Personal/Family и приглашение участника из референса не переносим.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Форма бюджета разбита на шаги с полосой прогресса и переходом вперёд и назад
- [ ] #2 Категории выбираются чипами с эмодзи; выбранные заливаются акцентом
- [ ] #3 Лимит задаётся на каждую выбранную категорию
- [ ] #4 Валюта бюджета выбирается явно
- [ ] #5 Незавершённый мастер не теряет введённое при переходе между шагами; выход запрашивает подтверждение
- [ ] #6 Шаги доступны с клавиатуры, текущий шаг объявлен экранному диктору
- [ ] #7 Новые строки в en.json и ru.json прогнаны через humanize-text
- [ ] #8 Проверено в обеих темах и на мобильной ширине; цели нажатия >=44px
- [ ] #9 Тесты формы обновлены; bun run test, lint, typecheck проходят
