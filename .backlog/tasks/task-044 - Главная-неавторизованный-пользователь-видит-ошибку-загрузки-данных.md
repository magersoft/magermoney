## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Если открыть главную без авторизации, вместо перехода на вход или понятного состояния показывается «ошибка загрузки данных». Запросы дашборда уходят без сессии и падают, а пользователь не понимает, что нужно войти.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Неавторизованный пользователь на главной не видит ошибку загрузки данных
- [ ] #2 Он попадает на экран входа (или видит явное предложение войти), после входа возвращается на главную
- [ ] #3 Запросы данных главной не отправляются, пока нет сессии
- [ ] #4 Настоящая ошибка загрузки у авторизованного пользователя по-прежнему показывается с возможностью повторить
- [ ] #5 Тесты покрывают состояния: нет сессии, ошибка загрузки, успех
<!-- AC:END -->
