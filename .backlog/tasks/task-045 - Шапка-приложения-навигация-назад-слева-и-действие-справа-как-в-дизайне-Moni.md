## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
На внутренних экранах в шапке нет привычной навигации назад, а сама шапка сложнее, чем в референсе Moni. В дизайне Moni шапка простая: слева кнопка навигации (назад), справа кнопка действия экрана. Нужно привести шапку приложения к этой схеме в рамках текущего дизайна.

Правая кнопка — контекстная: её смысл задаёт открытый экран, а не сама шапка. На форме редактирования счёта это «Сохранить» (сабмит формы прямо из шапки), на списке — «Добавить», на экране без действия место пустое. То есть нужен сквозной UX-флоу: экран объявляет своё действие (подпись, обработчик, состояния disabled/loading), шапка его показывает; при этом форма остаётся сабмитабельной и со своей страницы.

Переключатель темы из шапки убираем: селектор темы уже живёт в настройках (apps/web/src/modules/profile/ui/SettingsPage.vue), пусть остаётся только там.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Слева в шапке кнопка «назад» на экранах, куда заходят из другого экрана; на корневых экранах таба её нет
- [ ] #2 Справа в шапке кнопка действия, которое зависит от экрана; если действия нет, место пустое
- [ ] #3 Шапка упрощена до схемы «навигация слева, действие справа» по референсу Moni, без лишних элементов
- [ ] #4 Кнопки шапки доступны с клавиатуры и экранных читалок (подписи, размер области нажатия), корректно работают в светлой и тёмной теме
- [ ] #5 Все существующие экраны переведены на новую шапку, действия, которые раньше жили в шапке, не потеряны
- [ ] #6 Тесты покрывают показ и скрытие кнопки «назад» и слот действия
- [ ] #7 Экран задаёт действие для правой кнопки шапки: подпись, обработчик и состояния disabled/loading; шапка сама действий не придумывает
- [ ] #8 На экране редактирования/создания счёта правая кнопка — «Сохранить», она сабмитит форму и отражает её состояние (неактивна при невалидной форме, показывает загрузку при сохранении)
- [ ] #9 Переключатель темы убран из шапки; смена темы остаётся только на экране настроек и продолжает работать
<!-- AC:END -->
