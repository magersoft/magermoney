## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Самый ценный паттерн референса и прямое решение нашей проблемы: сейчас до добавления расхода три касания через План. У Moni центральная кнопка + раскрывается в шит, где сумма — первое и самое крупное поле, под ней сегмент типа операции, дальше поля-строки (иконка, метка, значение, шеврон) вместо полей с рамкой, внизу кнопка, а нумпад выезжает частью шита (слайд 13). Над клавиатурой — сетка быстрых сумм (слайд 20).

У нас сегмент из трёх пунктов (перевод, расход, доход — долгов нет), и рядом с суммой обязателен селектор валюты: у Moni валюта одна и потому не показана. Компоненты нужны всем формам ввода и задаче навигации TASK-002, которая этот шит открывает.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Поле-строка показывает иконку, метку и значение, открывает свой выбор и работает как настоящий контрол формы: метка связана, ошибка объявлена, фокус виден
- [ ] #2 Шит открывается снизу, содержит крупное поле суммы, сегмент типа, поля-строки и кнопку подтверждения внизу
- [ ] #3 Рядом с суммой есть селектор валюты
- [ ] #4 Есть сетка быстрых сумм над вводом
- [ ] #5 Шит закрывается по Esc, по нажатию вне и по кнопке; фокус захвачен внутри и возвращается на открывший элемент
- [ ] #6 Учтены safe-area снизу и появление экранной клавиатуры: кнопка подтверждения остаётся достижимой
- [ ] #7 Движение шита использует пресеты packages/ui/src/motion и уважает prefers-reduced-motion
