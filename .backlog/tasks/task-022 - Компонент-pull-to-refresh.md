## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Экраны приложения — PWA, и на телефоне список обновляют жестом «потянуть вниз». Сейчас такого жеста нет ни в packages/ui, ни в приложении. Нужен переиспользуемый компонент, который потом подключается на любой экран со списком, первым — на курсы валют.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Компонент оборачивает контент и по жесту вниз от верха прокручиваемой области вызывает событие refresh
- [ ] #2 Жест срабатывает только когда контент прокручен к самому верху и не мешает обычной прокрутке
- [ ] #3 Есть индикатор: тянется, готов к отпусканию, идёт обновление; порог и сопротивление подобраны так, чтобы жест ощущался естественно
- [ ] #4 Пока идёт обновление, повторный жест игнорируется; состояние управляется через prop или через промис из обработчика
- [ ] #5 Анимация берёт пресеты из packages/ui/src/motion и уважает prefers-reduced-motion
- [ ] #6 На десктопе без касания компонент ничего не ломает; для доступности есть альтернатива жесту (кнопка или доступное действие), её можно подключить снаружи
- [ ] #7 Экспортируется из packages/ui, покрыт тестами и историей/примером использования, если такие есть в пакете
<!-- AC:END -->
