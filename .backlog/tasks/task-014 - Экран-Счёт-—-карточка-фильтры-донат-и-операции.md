## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Wallet detail у Moni (слайды 12, 15) — самый насыщенный экран референса: карточка сверху, блок Overview со строкой чипов активных фильтров, две плитки доходов и расходов, донат по категориям с легендой, ниже список операций, сгруппированный по периоду.

Для нас это экран счёта. Операции на нём — записи баланса и переводы, у счёта одна валюта, поэтому сноска о курсе здесь не нужна, зато нужен выбор периода: тот же календарь-пикер отдельным шитом с кнопкой применения, что и у референса.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Чистое ядро уехало в application/account-period.ts (рядом с expense-groups.ts и build-dashboard.ts), а не в domain/: в этом проекте domain/ держит мапперы и метки, а сборка read-модели живёт в application. Сам файл остался чистым — Decimal, без Vue и без i18n.

Донат у счёта делит не категории (их у счёта нет), а оборот месяца по origin движения: «Перевод», «Поступление», «Вручную». В разрыве кольца — оборот, под ним подпись с чистым изменением остатка. Выбор слайса в легенде фильтрует список и вешает снимаемый чип. Решение согласовано с владельцем перед реализацией; гранулярность периода — месяц, тоже по согласованию.

Движение = дельта записи к предыдущей: балансы декларируются, а не считаются (CONTEXT.md). Первая в истории запись читается как приход всей суммы. Правка осталась только у самой свежей ручной записи — её строка рендерится как button, остальные как div.

BalanceTimeline.vue и его тест удалены: экран их больше не использует. Вместе с ними ушли ключи accounts.detail.history/sinceLast/byTransfer/byInflow. RowGroup в packages/ui получил prop variant='change', чтобы подытог дня показывал знак.

Проверено в браузере (localhost:5173, ширина окна 420px) в светлой и тёмной темах: шапка, карточка, кнопки, строка «Обзор» с пилюлей месяца, две плитки, кольцо, пустое состояние, шит выбора месяца (будущие месяцы недоступны, «Применить» меняет период, появляется чип «Июнь 2026 ×»). Данные подставить не удалось — локальный API отвечает 401 (сессия Supabase истекла), поэтому наполненные список/легенда проверены тестами, а не глазами.

Найдено попутно и НЕ чинилось (вне ACs): при ошибке загрузки журнала (401) экран показывает «Остатков ещё нет», то есть ошибка выглядит как пустой счёт. Это поведение было и раньше; родственно TASK-037.
