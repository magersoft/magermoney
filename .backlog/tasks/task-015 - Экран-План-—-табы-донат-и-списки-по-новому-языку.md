## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Экран Report у Moni (слайд 14): табы внутри экрана, под ними строка чипов-фильтров, плитки, донат с перелистыванием месяца стрелками, список с группировкой и подытогом. Экран Budgets (слайд 16): месячный бюджет с прогрессом и суммой потрачено из лимита, ниже категории со своими полосами, превышенная подсвечена.

У нас План уже собирает три сегмента — доходы, расходы, бюджеты — из соседних модулей через их баррели. Задача переводит его на табы и компоненты нового языка, не меняя, откуда берутся данные и не нарушая правило, что модуль данных не импортирует экраны другого модуля.

Табы референса (OVERVIEW / TRANSFER / DEBTS / RECEIPTS) не переносим: долгов и чеков у нас нет.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Plan

1. packages/ui: добавить TabBar (role=tablist/tab, стрелки, Home/End) + тест + экспорт — таба как паттерн у нас ещё нет.
2. PlanPage: TabBar + tabpanel, таб живёт в query (как сейчас), + ведёт на форму активного таба.
3. income/application/income-groups.ts (чистая функция + тест): регулярные / нерегулярные источники, подытог на руки в валюте показа, несконвертируемые отдельно. IncomeSegment на RowGroup + TransactionRow, пустое состояние с действием.

6. Новые строки локалей через humanize-text; проверить обе темы и мобильную ширину; цели >=44px.
7. Обновить тесты экранов/сегментов; bun run test, lint, typecheck.
