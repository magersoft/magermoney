## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
В форме счёта (apps/web/src/modules/accounts/ui/AccountFormPage.vue) страна вводится вручную двухбуквенным кодом, и флага там не видно. Нужен нормальный выбор: список стран с поиском (автокомплит), у каждой страны свой флаг. Для этого в подмножество иконок надо добавить флаги всех стран, а не только тех, что привязаны к валютам. Зависит от задачи про приоритет флага страны.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Combobox взят из shadcn-vue (@shadcn/combobox, reka-nova) и положен в packages/ui/src/components/ui/combobox с относительными импортами. CLI при добавлении полез обновлять @vueuse/core до 15, @lucide/vue и дописывать в styles/index.css импорт шрифта Geist и свой base-слой — всё это откачено, из пакета взяты только файлы combobox. ComboboxInput переписан без input-group (в этой системе его нет): поисковая иконка и линия под полем.

CountrySelect держит язык строк формы: поверхность, 56px, подпись над значением, шеврон. Очистка — отдельная кнопка (вложенная кнопка внутри кнопки невалидна), на грубом указателе 44px, как и строки списка.

Обязательность: комбобокс — не input с required, поэтому форма сама не отправляется без страны и показывает accounts.form.countryRequired через aria-invalid/aria-describedby.

Названия стран взяты из Intl.DisplayNames (CLDR) для ru и en, 257 кодов; сокращения вида «О-в»/«ОАЭ»/«КНДР» развёрнуты.

Бандл: входной чанк 928,59 -> 940,70 КБ (gzip 292,93 -> 298,74) — это 514 названий в двух локалях; 161,52 КБ флагов (gzip 35,41) остались отдельным country-flags-*.js.

Проверка: bun run test, typecheck, lint, vite build.
<!-- SECTION:NOTES:END -->
