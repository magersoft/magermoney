## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
В форме счёта (apps/web/src/modules/accounts/ui/AccountFormPage.vue) страна вводится вручную двухбуквенным кодом, и флага там не видно. Нужен нормальный выбор: список стран с поиском (автокомплит), у каждой страны свой флаг. Для этого в подмножество иконок надо добавить флаги всех стран, а не только тех, что привязаны к валютам. Зависит от задачи про приоритет флага страны.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Поле страны — combobox с поиском: ищет по названию на текущем языке (ru/en) и по коду ISO 3166-1 alpha-2
- [ ] #2 Каждый вариант в списке и выбранное значение показывают флаг страны
- [ ] #3 В подмножество иконок добавлены флаги всех стран, размер бандла проверен и не раздувает входной чанк
- [ ] #4 Список стран и их названия живут в одном месте, названия локализованы через locales/en.json и ru.json
