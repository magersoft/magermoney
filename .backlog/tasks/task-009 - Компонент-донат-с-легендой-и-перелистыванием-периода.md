## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Донат у Moni стоит на трёх экранах и в двух ролях: как разбивка расходов по категориям с цветной легендой из чипов (слайды 12, 14) и как прогресс бюджета с остатком в центре (слайд 10). По бокам — стрелки перелистывания месяца, в разрыве дуги — сумма периода.

Это единственная диаграмма в приложении, и она обязана быть читаемой без цвета: категории различаются не только тоном, а легенда несёт и сумму, и название. Прогресс бюджета — та же дуга с одним сегментом.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Токены: пара ролей для сегментов доната — `--mm-segment-l` / `--mm-segment-c` (дуга: насыщенный тон, различимый на карточке) по образцу `--mm-tint-*`; оттенок раздаётся золотым углом по индексу сегмента, как у карточки счёта.
2. Тесты сначала: в `tokens-contrast.test.ts` — прогон всех 360° (дуга >= 3:1 к карточке и полотну в обеих темах, внутри sRGB); в `donut.test.ts` — геометрия, оба режима, пустое состояние, превышение, смена периода, легенда.
3. `components/donut/segments.ts`: чистая геометрия (дуга в SVG-пути, доли, проценты) + `segmentHue`. Числа для рисования, строки-десятичные для показа — правило ProgressRule.
4. `Donut.vue`: дуга с зазором между сегментами, в центре AmountLockup + название периода, по бокам кнопки перелистывания (>=44px), `role="img"` со сводкой по сегментам.
5. `DonutLegend.vue`: чипы «точка + название + сумма», связанные с сегментом (наведение/фокус подсвечивает дугу, `aria-pressed`).
6. Режим прогресса: один сегмент, остаток — утопленная дорожка; превышение даёт `data-over` и передаётся не только цветом.
7. Экспорт из `packages/ui/src/index.ts`; test, lint, typecheck.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Решения.

- **Один компонент на две роли.** `DonutChart` с `mode="breakdown" | "progress"`: прогресс бюджета — та же дуга с одним сегментом против той же дорожки. Второй донат разошёлся бы с первым за месяц. Имя многословное не по вкусу, а по правилу `vue/multi-word-component-names`.
- **Геометрия — пунктиром, не путями дуг.** Один `<circle>` на сегмент со `stroke-dasharray` и `stroke-dashoffset`, кольцо повёрнуто на −90° и потому открывается на двенадцати часах. Путь дуги — тригонометрия с флагом large-arc, который ломается ровно на тех размерах, которые никто не проверяет; пунктир — два числа, и оба читаются в тесте.
- **Зазор вычитается из дуг, а не добавляется между ними** (кольцо обязано остаться кольцом), и это же делает двух соседей различимыми, когда их тона рядом. Единственный сегмент зазора не получает — ему не от кого отделяться. Сегмент меньше зазора не исчезает, а сохраняет минимальный штрих `DONUT_MIN_ARC`: категория на 0.3% месяца всё-таки случилась.
- **Палитра сегментов — та же механика, что у тинта карточки, но с другого конца шкалы.** Категория выбирает только оттенок (золотой угол от брендовых 262°, чтобы первый — самый крупный — сегмент был брендовым синим, а не красным, который в этой палитре значит «превышение»), светлоту и цветность фиксирует тема: `--mm-light-segment-l/c: 0.56 / 0.09`, `--mm-dark-...: 0.74 / 0.115`. Тинт лежит под чернилами, дуга лежит на поверхности — отсюда 1.4.11 и 3:1 вместо AA, и проверка идёт по всем 360° на каждой поверхности, на какую диаграмма может попасть (худшее: 3.7 в светлой, 5.2 в тёмной), плюс весь круг внутри sRGB — иначе gamut mapping схлопнул бы далёкие оттенки в один цвет и «одна категория — один цвет» молча сломалось бы.
- **Подписи никогда не набраны цветом сегмента.** Легенда — чипы на утопленной поверхности чернилами, точка цвета — самая мелкая часть чипа. Поэтому AA для подписей держится сам собой, в обеих темах, при любом оттенке дуги.
- **Читается без цвета.** Легенда даёт имя и сумму каждому сегменту, доступное имя диаграммы — весь разбор одной фразой (`role="img"` в разбивке, `role="progressbar"` с `aria-valuetext` в прогрессе). Превышение лимита объявлено словами и иконкой, не только красным, потому что дуге дальше идти некуда.
- **Слова пишет экран.** Компонент форматирует числа и только их; `label`, `period`, `caption`, `emptyLabel`, `overLabel` и имена стрелок приходят снаружи — копирайт живёт в локалях приложения.
