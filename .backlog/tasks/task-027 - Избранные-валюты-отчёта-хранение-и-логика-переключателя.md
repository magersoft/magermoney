## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Переключатель валюты отчёта (CurrencySwitch) показывает варианты из `useDisplayCurrency().options`, и набор сейчас определяется кодом. Когда валют станет много (TASK-025), переключатель должен показывать только те, что человек отметил избранными. Лимит три: больше не помещается рядом с логотипом и кнопкой темы на телефоне (об этом в комментарии CurrencySwitch), и переключатель остаётся быстрым.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Избранные валюты хранятся на пользователя (например поле в profiles или отдельная таблица) с RLS; порядок сохраняется
- [ ] #2 Максимум три избранные валюты: лимит проверяется в use case и в БД, попытка добавить четвёртую даёт понятную ошибку
- [ ] #3 Избранными можно сделать только подключённые валюты; отключение валюты убирает её из избранных, если она не последняя
- [ ] #4 Всегда есть хотя бы одна избранная валюта; текущая валюта отчёта входит в избранные, а при её удалении из избранных переключается на первую оставшуюся
- [ ] #5 useDisplayCurrency.options отдаёт избранные, остальные экраны продолжают работать с current без изменений
- [ ] #6 Работает офлайн: изменение проходит через очередь мутаций (rates/offline.ts)
